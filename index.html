IFT 203 - WEB TECH
Web technology is the foundation of how computers communicate, share information, and run applications across the internet.
The Three Core Pillars of Web Pages

Every standard website relies on three main front-end technologies:
  • HTML (Hypertext Markup Language): Builds the basic structure and layout of a webpage
  • CSS (Cascading Style Sheets): Controls the visual design, colors, fonts, and responsiveness.
  • JavaScript: Adds interactive behavior, dynamic updates, and animations.
Under the Hood: Client-Server Architecture Web applications operate using a request-response model over the HTTP protocol: • The Client: Your web browser (such as Chrome, Firefox, or Safari) sends a request to a server. • The Server: Processes the request, interacts with databases (like PostgreSQL, MySQL, or MongoDB), and sends back the webpage data. • APIs & Data: Formats like JSON or RESTful APIs allow front-end interfaces to talk smoothly to back-end services (built with languages like Python, Node.js, or PHP).
